# 2분 데모

모든 CSV는 합성 데이터입니다. 실측 ESG 성과·학습 모델 정확도를 주장하지 않습니다.

1. 예정일 2026-09-17, 600명, 참석률 80%, 추가 0명, 안전여유 5%로 계산합니다.
2. 예상 식수 480명과 조리량 504명을 설명합니다.
3. 쌀 25.4kg, 두부 20.32kg, 당근 5.12kg 발주 추천을 보여줍니다.
4. 추가 인원 칸에 35명을 입력하고 다시 계산합니다.
5. 예상 515명, 조리 541명, 발주 쌀 29.1kg·두부 23.28kg·당근 6.23kg를 확인합니다.
6. 소비기한 9월 16일인 당근 C000은 제외되고 두부 T001부터 배분됨을 보여줍니다.

현재 추가 인원은 숫자 입력으로 받습니다. 자연어 "35명 추가" 처리는 후속 작업입니다.
