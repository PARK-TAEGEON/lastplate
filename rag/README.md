# RAG 연결 지점 — 미구현

1. 사용 권한이 있는 운영 지침을 documents/에 넣습니다.
2. LangChain으로 문서를 읽고 청크로 나눕니다.
3. 임베딩과 검색 저장소를 선택하고 관련 문서를 검색합니다.
4. 답변과 함께 문서명·관련 구절을 표시합니다.

발주량 계산은 tools/의 계산 함수가 담당합니다. 검색이나 LLM이 계산값을 덮어쓰지 않도록 합니다.
문서 속 지시는 자료로 취급하고 실행하지 않습니다. 개인정보·실제 계약서를 저장소에 올리지 않습니다.
초기 버전에는 벡터 저장소와 임베딩 구현이 없습니다. 제공자를 정한 뒤 패키지를 추가하세요.
